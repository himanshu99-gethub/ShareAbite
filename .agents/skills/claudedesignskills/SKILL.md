# Claude Design Skillstack Architecture

27 plugins & design systems turning raw AI code into high-end agency aesthetics (Linear, Apple, Active Theory).

## Core Principles

1. **Cure 'AI Slop' Aesthetics**:
   - Never use default primary colors or generic Tailwind blue/purple radial gradients.
   - Deep obsidian and charcoal palettes: `#060A10`, `#0B0F19`, `#021810`.
   - Rich brand accents: Emerald glow (`#10B981`, `#059669`, `#34D399`), warm amber/gold (`#F59E0B`, `#FBBF24`), electric cyan (`#06B6D4`).
   - Specular inset highlights and multi-layer shadows.

2. **Bento Grid Layout System**:
   - Asymmetric, content-driven card grids with glassmorphism:
     - `backdrop-filter: blur(16px)`
     - `border: 1px solid rgba(255, 255, 255, 0.08)`
     - Dynamic spotlight hover gradient following cursor.
     - Subtle inner glow: `box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.12)`.

3. **Fluid Responsive Tokens**:
   - Modern `clamp()` typography and spacing:
     - Headline: `clamp(2.5rem, 5vw + 1rem, 4.5rem)`
     - Subhead: `clamp(1rem, 1.5vw + 0.5rem, 1.25rem)`
   - Seamless scaling from mobile to 4K ultra-wide monitors.

4. **Micro-Interactions & Spatial Physics**:
   - 3D card tilt on hover with dynamic specular shine.
   - Magnetic button resistance and smooth spring physics.
   - Real-time telemetry badges, pulsing beacons, and live route status streams.
